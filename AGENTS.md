# Financial Intelligence Radar — durable instructions

Build an evidence-first, zero-cost SEC disclosure intelligence product for analyst research—not investment advice, recommendations, price prediction, or a chatbot. Preserve raw source payloads, filing identity, timestamps and accession numbers. Never turn missing data into zero.

Canonical observations need a data-quality state, period type, provenance, source concept, and derivation lineage. Do not mix annual, YTD and standalone-quarter durations. Suppress signals when data is invalid or incomparable. Keep dependencies free and run pytest before changing GitHub.
